# DevHub macOS releases

Public download assets for [DevHub](https://github.com/cobuci/devhub-macos) (private source).

Each GitHub Release here contains:

- `DevHub-x.y.z.dmg` — install by opening the DMG and dragging to Applications
- `appcast.xml` — Sparkle feed (`https://github.com/cobuci/devhub-macos-releases/releases/latest/download/appcast.xml`)

Do not put source code here.
